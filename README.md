# medas-entity-manager

Part of the [Medas framework](https://github.com/tarantuli/medas-core).

## Description

The ORM layer of the Medas framework. Entity classes are plain PHP objects annotated with attributes; the entity manager handles identity mapping, change tracking, hydration, flushing, and querying through a storage-backend-agnostic `Flusher` interface.

**Core concepts:**

- **Identity map** — `EntityManager::get()` always returns the same object instance for a given class and id pair within a request. Subsequent calls for the same id are served from the in-memory map without hitting storage.
- **Change tracking** — on `persist()` a snapshot of the entity's property values is saved. On `flush()` the snapshot is diffed to detect which properties changed, and only modified entities are written.
- **Lifecycle hooks** — `BeforeFlushHandler` and `AfterFlushHandler` implementations are called during every flush. Both `medas-entity-events` and `medas-entity-change-log` plug in through these hooks.
- **Selectors** — a `Selector` describes a query as a `Definition` containing conditions, sorts, joins, groupings, pagination, and output values. The storage backend translates it to SQL or any other query language.
- **Repository** — `Repository` wraps `EntityManager` with higher-level fetch methods including `fetchAll`, `fetch`, `fetchOne`, `getOrCreate`, and `fetchOrCreate` (with built-in duplicate-key race-condition handling).

**Entity attributes:**

| Attribute                          | Target   | Description                                                     |
|------------------------------------|----------|-----------------------------------------------------------------|
| `#[Entity(store?, storage?)]`      | Class    | Marks a class as a managed entity                               |
| `#[Id]`                            | Property | Marks the identity property (`Uuid` or `int`)                   |
| `#[IsCreationTimestamp]`           | Property | Set automatically to `now` on first persist                     |
| `#[IsModificationTimestamp]`       | Property | Updated automatically on every flush                            |
| `#[IsUnique]`                      | Property | Adds a unique constraint                                        |
| `#[IsIndex]`                       | Property | Adds a non-unique index                                         |
| `#[IsGeneratedValue]`              | Property | Value is generated by the storage backend (e.g. auto-increment) |
| `#[References(entity, property?)]` | Property | Declares a foreign-key relation                                 |
| `#[CompoundIndex]`                 | Class    | Multi-column index                                              |
| `#[UniquePropertySet]`             | Class    | Multi-column unique constraint                                  |
| `#[StoreOriginalEntityType]`       | Class    | Stores the original class name for polymorphic relations        |
| `#[Unmanaged]`                     | Property | Excludes a property from persistence                            |
| `#[AddOwnershipFilter]`            | Class    | Applies an ownership filter to all queries                      |

The `Timestamps` trait adds `#[IsCreationTimestamp] $createdAt` and `#[IsModificationTimestamp] $modifiedAt`, both marked `#[DontLogChanges]`.

## Configuration options

| Option                              | Default           | Description                                 |
|-------------------------------------|-------------------|---------------------------------------------|
| `entity-manager.entity-directories` | `['src']`         | Directories scanned for entity class files  |
| `entity-manager.default-on-delete`  | (storage default) | Default `ON DELETE` action for foreign keys |
| `entity-manager.default-on-update`  | (storage default) | Default `ON UPDATE` action for foreign keys |

## Usage

### Package developer context

Register the package and inject `EntityManager` and `Repository`:

```php
use Medas\EntityManager\EntityManagerPackage;

EntityManagerPackage::instance();
```

**Defining an entity:**

```php
use Medas\Core\Interfaces\{HasId, Uuid};
use Medas\EntityManager\Attributes\{Entity, Id, IsUnique, References};
use Medas\EntityManager\Traits\Timestamps;

#[Entity(store: 'invoices')]
class Invoice implements HasId
{
    use Timestamps;

    #[Id]
    public Uuid $id;

    #[IsUnique]
    public string $number;

    public string $status;

    public int $amountCents;

    #[References(Customer::class)]
    public Customer $customer;

    public function id(): Uuid
    {
        return $this->id;
    }
}
```

**Creating and persisting entities:**

```php
use Medas\Core\Interfaces\EntityManager;
use Medas\Core\Attributes\Service;

#[Service]
readonly class InvoiceService
{
    public function __construct(
        private EntityManager $entityManager,
    ) {}

    public function create(Customer $customer, int $amountCents): Invoice
    {
        /** @var Invoice $invoice */
        $invoice = $this->entityManager->create(Invoice::class, [
            'number'      => $this->generateNumber(),
            'status'      => 'draft',
            'amountCents' => $amountCents,
            'customer'    => $customer,
        ]);

        $this->entityManager->persist($invoice);
        $this->entityManager->flush();

        return $invoice;
    }

    public function markPaid(Invoice $invoice): void
    {
        $invoice->status = 'paid';

        // No explicit persist() needed — entity is already in the identity map
        $this->entityManager->flush();
    }

    public function remove(Invoice $invoice): void
    {
        $this->entityManager->delete($invoice);
        $this->entityManager->flush();
    }
}
```

**Fetching by id:**

```php
// Returns the same object instance for repeated calls with the same id
$invoice = $this->entityManager->get(Invoice::class, $id);
```

**Fetching with `Repository`:**

```php
use Medas\EntityManager\Repository;

// All entities of a type
$invoices = $repository->fetchAll(Invoice::class);

// By property values
$drafts = $repository->fetch(
    new Selector\Selectors\WithValues(Invoice::class, ['status' => 'draft'])
);

// Single result
$invoice = $repository->fetchOne(
    new Selector\Selectors\WithValues(Invoice::class, ['number' => 'INV-001'])
);

// Get or create — handles duplicate-key race conditions automatically
$customer = $repository->getOrCreate(
    Customer::class,
    ['email' => 'alice@example.com'],
    fn() => ['name' => 'Alice'],
);
```

**Building a custom Selector:**

```php
use Medas\EntityManager\Selector\{Definition, Pagination, Selector};
use Medas\EntityManager\Selector\Conditions\{WhereIs, WhereIsNull, WhereIn};
use Medas\EntityManager\Selector\Operants\{Property, Value, Values};
use Medas\EntityManager\Selector\Sorting\{SortBy, SortDirection};

class OpenInvoicesSelector implements Selector
{
    public function entity(): string
    {
        return Invoice::class;
    }

    public function definition(): Definition
    {
        return Definition::create(Invoice::class)
            ->add(new WhereIn(new Property('status'), new Values(['draft', 'sent'])))
            ->add(new WhereIsNull(new Property('paidAt')))
            ->add(SortBy::c(new Property('createdAt'), SortDirection::DESC))
            ->add(Pagination::c(page: 1, perPage: 25));
    }
}

$invoices = $repository->fetch(new OpenInvoicesSelector());
```

**Memory management for batch processing:**

```php
// Trigger a purge when the identity map reaches 1000 entities,
// evicting the 250 least-recently-used entries
$this->entityManager->setPurgingParameters(triggerSize: 1000, purgeAmount: 250);

foreach ($largeDataset as $row) {
    $entity = $this->entityManager->create(MyEntity::class, $row);
    $this->entityManager->persist($entity);
}

$this->entityManager->flush();
```

**Discarding an entity after a failed INSERT:**

```php
try {
    $this->entityManager->persist($entity);
    $this->entityManager->flush();
} catch (StorageException $e) {
    if ($e->exceptionType === StorageExceptionType::DuplicateKey) {
        $this->entityManager->discard($entity);
    }
}
```

### Backend user context

**Configuring entity directories:**

```yaml
entity-manager:
  entity-directories:
    - src/Entities
    - src/Modules/Billing/Entities
```

All `.php` files in the configured directories are scanned for `#[Entity]` classes at bootstrap.

**Relation cascade actions:**

```yaml
store-names:
  default-on-delete: CASCADE
  default-on-update: CASCADE
```

Override per-property with `#[OnDelete(Action::SetNull)]` or `#[OnUpdate(Action::Restrict)]`.

**Available `Condition` types for selectors:**

`WhereIs`, `WhereIsNot`, `WhereIn`, `WhereNotIn`, `WhereIsNull`, `WhereIsNotNull`, `WhereIsTruthy`, `WhereContains`, `WhereStartsWith`, `WhereEndsWith`, `WhereIsMoreThan`, `WhereIsLessThan`, `WhereIsAtLeast`, `WhereIsAtMost`.
